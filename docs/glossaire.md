# Glossaire de l'interface

Mot unique affiché aux personnes (bot, tableau de bord, site, docs) pour chaque concept. Les
identifiants techniques restent en anglais (voir `.claude/conventions-nommage.md`). Un nouveau mot
entre ici **avant** d'apparaître dans l'interface. Tenu par l'agent `nommage`.

Relevé fait sur le vocabulaire déjà en usage dans `apps/web`, `apps/bot` et `packages/shared`.

| Terme affiché           | Définition courte                                                                       | Identifiant technique                        | À ne pas employer                             |
| ----------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------- | --------------------------------------------- |
| serveur                 | Un serveur Discord où le bot est installé                                               | `guild`, `guildId`, `Guild`                  | guilde, server                                |
| membre                  | Personne présente sur un serveur                                                        | `member` ; option de commande `membre`       | joueur (hors Division 2), user                |
| utilisateur             | Compte Discord, hors du contexte d'un serveur (ex. débannir)                            | `user`, `userId`                             | membre pour une personne non présente         |
| salon                   | Salon textuel d'un serveur                                                              | `channel`, `…ChannelId`                      | channel, canal                                |
| catégorie               | Regroupement de salons (tickets)                                                        | `TicketType.categoryId`                      | dossier                                       |
| rôle                    | Rôle Discord d'un serveur                                                               | `role`, `…RoleId`, `…RoleIds`                | grade                                         |
| tableau de bord         | Le site de gestion d'un serveur                                                         | `dashboard`, route `/dashboard`              | dashboard, panel                              |
| onglet                  | Une section du tableau de bord, une par module                                          | `DashboardModule`, `GUILD_TABS`              | page, menu                                    |
| accès délégué           | Droit donné par un admin à un membre d'ouvrir certains onglets                          | `GuildDelegate`, route `acces`               | permission, invité                            |
| délégué                 | Membre qui détient un accès délégué                                                     | `delegate`                                   | modérateur du site                            |
| ticket                  | Demande d'aide ouverte dans un salon dédié                                              | `Ticket`, `tickets`                          | billet                                        |
| transcript              | Copie archivée d'un ticket fermé                                                        | clé S3 `<guildId>/<id>.html`                 | journal du ticket                             |
| sanction                | Mesure de modération prise contre un membre                                             | `Case`, `/sanctions`                         | punition                                      |
| avertissement           | Sanction : simple rappel à l'ordre                                                      | `CaseType.WARN`                              | warn (en interface)                           |
| sourdine                | Sanction : membre rendu muet pour une durée                                             | `CaseType.MUTE`                              | mute (en interface)                           |
| expulsion               | Sanction : retrait du serveur, retour possible                                          | `CaseType.KICK`                              | kick (en interface)                           |
| bannissement            | Sanction : exclusion durable                                                            | `CaseType.BAN`                               | ban (en interface)                            |
| niveau                  | Palier d'ancienneté gagné avec l'XP                                                     | `leveling`, `LEVELING`                       | rang, level                                   |
| XP                      | Points d'expérience gagnés en écrivant                                                  | `xp…`                                        | points                                        |
| classement              | Liste des membres par XP                                                                | `leaderboard`, `/classement`                 | leaderboard (en interface)                    |
| panneau de rôles        | Message avec boutons pour s'attribuer des rôles                                         | `RolePanel`, `role-panels`                   | menu de rôles                                 |
| giveaway                | Tirage au sort avec récompense                                                          | `Giveaway`, `giveaways`                      | concours (non employé à ce jour)              |
| gagnant                 | Membre tiré au sort                                                                     | `winner`                                     |                                               |
| sortie                  | Activité planifiée (raid, incursion) de The Division 2                                  | `td2`, page publique `/sorties`              | event, événement                              |
| signalement             | Report d'un joueur au réseau The Division 2                                             | `td2Report…`                                 | report (en interface)                         |
| **Bienvenue** (onglet)  | Onglet du module qui accueille les arrivées et salue les départs                        | `DashboardModule.WELCOME`, `welcome`         | Accueil (réservé à la page d'accueil du site) |
| **message d'arrivée**   | Texte envoyé dans un salon quand un membre rejoint le serveur                           | `welcomeMessage`                             | message de bienvenue, join message            |
| **message de départ**   | Texte envoyé dans un salon quand un membre quitte le serveur                            | `goodbyeMessage`                             | message d'au revoir, leave message            |
| **rôle d'arrivée**      | Rôle donné automatiquement à chaque nouveau membre                                      | `welcomeRoleId`                              | rôle par défaut, rôle de bienvenue, autorôle  |
| **variable de message** | Mot entre accolades remplacé à l'envoi : `{membre}` `{pseudo}` `{serveur}` `{effectif}` | `WELCOME_VARIABLES`, `renderWelcomeTemplate` | placeholder, balise                           |

Mots ajoutés pour l'onglet « Modération » du tableau de bord (à valider) :

| Terme affiché                  | Définition courte                                                                                                                                                                             | Identifiant technique                                                              | À ne pas employer                                   |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------- |
| **Modération** (onglet)        | Onglet du module des sanctions : liste, fiche d'un membre, levée                                                                                                                              | `DashboardModule.MODERATION`, `moderation`                                         | Sanctions (nom d'onglet), Mod                       |
| **numéro de sanction**         | Numéro propre au serveur, écrit `#12` ; « sanction » est déjà défini plus haut                                                                                                                | `Case.number`                                                                      | case, id, dossier                                   |
| **levée**                      | État d'une sanction annulée par un modérateur (débannissement, fin de sourdine, retrait d'un avertissement) ; l'origine de la levée (commande, levée automatique, tableau de bord) est gardée | `Case.revokedAt`, `Case.revokedVia`, `RevocationSource`, `caseStatus`              | révoquée, annulée, supprimée                        |
| **lever** (une sanction)       | Verbe du bouton « Lever la sanction » pour un bannissement ou une sourdine : « Lever le bannissement », « Lever la sourdine »                                                                 | `liftSanction`, `revoke` (route API)                                               | révoquer, annuler, débannir (réservé à la commande) |
| **retirer** (un avertissement) | Verbe pour un avertissement, qui n'a pas de sanction de fin : « Retirer l'avertissement », log « Avertissement retiré »                                                                       | `clearwarn`, `liftSanction`                                                        | lever, effacer, supprimer                           |
| **active**                     | État d'une sanction en cours, non levée (avertissement, ou durée pas encore écoulée)                                                                                                          | `caseStatus` → `active`                                                            | en cours, valide                                    |
| **terminée**                   | État d'une sourdine arrivée à échéance sans levée ; un bannissement temporaire échu mais pas encore levé reste « active » : le membre est encore banni                                        | `Case.expiresAt` dépassée, `caseStatus` → `ended`                                  | expirée, échue, finie                               |
| **fiche du membre**            | Vue du tableau de bord regroupant toutes les sanctions d'un membre                                                                                                                            | route web `…/moderation/membres/$userId`, route API `…/moderation/members/:userId` | profil, dossier, historique                         |
| **modérateur**                 | Membre qui a pris ou levé la sanction ; sans rapport avec un délégué du tableau de bord                                                                                                       | `Case.moderatorId`                                                                 | staff, mod, admin                                   |
| **cible**                      | Membre visé par une sanction                                                                                                                                                                  | `Case.targetId`                                                                    | victime, sanctionné, utilisateur                    |
| **raison**                     | Motif saisi avec la sanction ; « Aucune raison fournie » s'il manque                                                                                                                          | `Case.reason`, `NO_REASON` (bot)                                                   | motif, cause                                        |

Mots ajoutés pour la conservation des sanctions et la recherche par pseudo (à valider) :

| Terme affiché                    | Définition courte                                                                                                                                                                                                                                                         | Identifiant technique                                                    | À ne pas employer                                         |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------- |
| **close** (sanction)             | Sanction qui n'est plus d'actualité : levée, sourdine terminée, ou sanction ponctuelle (expulsion, débannissement, fin de sourdine). Seules les sanctions closes sont purgées. Contraire : « active ». Un bannissement temporaire échu non levé reste active              | `purgeCases` (`case-retention.ts`)                                       | périmée, archivée, terminée (réservé à la sourdine échue) |
| **conservation des sanctions**   | Réglage de l'onglet Général : durée après laquelle les sanctions closes sont supprimées (6, 12 par défaut, 24 mois, ou « Jamais ») ; réservé aux administrateurs du serveur                                                                                               | `GuildConfig.caseRetentionMonths`, `CASE_RETENTION_CHOICES`              | rétention, durée de vie, archivage                        |
| **purge** (des sanctions)        | Suppression automatique, chaque nuit, des sanctions closes plus anciennes que la conservation ; jamais appliquée aux sanctions actives                                                                                                                                    | `purgeCases`, file `moderation`, tâche `purge`                           | nettoyage, ménage (en interface), suppression             |
| **action en cours** (occupation) | Message « Une autre action de modération vise déjà ce membre : réessaie dans quelques secondes. », renvoyé quand une autre action tient déjà le verrou du membre                                                                                                          | `MODERATION_BUSY_MESSAGE`, clé `moderation:lock:<guildId>:<targetId>`    | verrou, lock, occupé (en interface)                       |
| **recherche par pseudo**         | Recherche d'une sanction par le début du pseudo d'un membre encore sur le serveur (en plus du numéro, de l'identifiant Discord et d'un mot de la raison) ; le texte fait 2 à 32 caractères, et les identifiants trouvés couvrent la cible ET le modérateur d'une sanction | `CasePage.nameSearch`, `member-search.ts`, clé `discord:member-search:…` | recherche par nom, par nom d'utilisateur                  |

Choix de « close » : « terminée » et « en cours » ont déjà un sens précis (sourdine échue ; « active » est le mot retenu pour
l'état d'une sanction non levée). Un mot distinct évite de purger « les terminées » en laissant croire qu'un
bannissement temporaire échu l'est aussi.

Mots ajoutés pour les types de tickets, le formulaire, la prise en charge, la note et la fermeture automatique (à valider) :

| Terme affiché             | Définition courte                                                                                                                                                                                                                                                                        | Identifiant technique                                                              | À ne pas employer                              |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------- |
| **type de ticket**        | Motif d'ouverture configuré par serveur : nom, catégorie, rôles de l'équipe, questions, délai d'inactivité. « catégorie » reste la catégorie Discord                                                                                                                                     | `TicketType`, `Ticket.typeId`, route API `tickets/types`                           | catégorie (de ticket), motif, sujet            |
| **formulaire**            | Questions posées à l'ouverture d'un ticket d'un type donné ; les réponses sont postées dans le salon, jamais gardées en base                                                                                                                                                             | `ticket:form`, `buildTicketModal`, `readFormAnswers`                               | modal, questionnaire, fiche                    |
| **question**              | Une question du formulaire d'un type (0 à 5), courte ou paragraphe, obligatoire ou non                                                                                                                                                                                                   | `TicketTypeQuestion`, `TicketTypeQuestionStyle`                                    | champ, field                                   |
| **prendre en charge**     | Action d'un membre de l'équipe qui se saisit d'un ticket ouvert ; définitive, un seul gagnant. État : « pris en charge par X »                                                                                                                                                           | `claimTicket`, `claimedById`, `claimedByName`                                      | assigner, réclamer, claim (en interface)       |
| **note de satisfaction**  | Note de 1 à 5 donnée par l'auteur du ticket après la fermeture, une seule fois ; seules des moyennes sont affichées, masquées sous 5 notes : moyenne par type visible avec l'onglet Tickets, moyenne par membre de l'équipe réservée aux administrateurs ; aucun nombre de notes affiché | `Ticket.rating`, `ratedAt`, `ticketRatingSchema`, `TicketStats`, `maskRatingStats` | score, avis, étoiles                           |
| **membre de l'équipe**    | Membre qui détient un des rôles d'un type de ticket et traite les tickets de ce type                                                                                                                                                                                                     | `staffRoleIds`                                                                     | agent, staff (en interface), support           |
| **délai d'inactivité**    | Durée sans message (12 h, 24 h, 48 h, 72 h ou 7 j) après laquelle un ticket est fermé ; réglé par type, désactivé par défaut                                                                                                                                                             | `TicketType.inactivityHours`, `TICKET_INACTIVITY_CHOICES`                          | timeout, expiration, durée de vie              |
| **rappel d'inactivité**   | Message posté à la moitié du délai, qui mentionne l'auteur ; la fermeture ne peut pas précéder le rappel                                                                                                                                                                                 | `Ticket.inactivityRemindedAt`                                                      | avertissement (réservé aux sanctions), relance |
| **fermeture automatique** | Fermeture d'un ticket faute d'activité après le délai, avec transcript ; affichée « Fermé automatiquement »                                                                                                                                                                              | `TicketCloseSource.INACTIVITY`, `Ticket.closedVia`, tâche `inactivity`             | expiration, archivage, purge                   |

Notes sur les variables de message (à figer avant le code) :

- `{membre}` : mention du membre ; `{pseudo}` : son nom affiché sans mention ; `{serveur}` : nom
  du serveur ; `{effectif}` : nombre de membres du serveur (et non `{nombre}`, déjà pris par l’option de `/clear`).

Les lignes en gras sont les mots **ajoutés** pour le module de bienvenue ; ils restent à valider
avec le choix final des noms.
